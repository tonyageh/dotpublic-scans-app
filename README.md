# dotPublic scans

The home-screen app for the dotPublic scanner. It starts a scan in the private
dotPublic-scanner repository and lists the finished reports. It holds no
reports and no keys: each device keeps its own GitHub key in its own browser.

Open it in Safari on the iPhone, then Share, then 'Add to Home Screen'.

The font is Atkinson Hyperlegible, by the Braille Institute, under the SIL Open
Font Licence 1.1, and is included in index.html.
